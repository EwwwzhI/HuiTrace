# DM Sans

`dm-sans-latin.woff2` is the unmodified Latin variable font from the application's previous successful Google Fonts/Next.js build. Its embedded metadata identifies DM Sans 9pt, with weight axis 100–1000 and copyright © 2014 The DM Sans Project Authors.

SHA-256: `468D56B6B25B05B70190B6C233D773F6F1770E8579827CE022A57F03FA8002FB`.

License: SIL Open Font License 1.1, included in `DM-Sans-OFL.txt`; upstream: https://github.com/google/fonts/tree/main/ofl/dmsans.

The application imports this committed file with `next/font/local`. No Google Fonts download is needed during development, production builds, or runtime. Characters outside this subset continue to use system fallback fonts.
