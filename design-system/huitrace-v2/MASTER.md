# HuiTrace V2 · Calm Bento

用户方向：苹果式简洁精致，大小错落的 Bento 卡片，双主题、柔和阴影、细腻但不拖慢操作的反馈。保留会迹名称、既有太极声波 Logo 和所有已有路由/入口。

参考：ui-ux-pro-max 的 `bento-box-grid`（已核对为 Bento Box Grid，桌面工具适用）。通用设计系统搜索给出的营销页与扁平风格不适用，因此不采用。实施以本文件和代码中的语义 token 为准。

- 首页：大幅录音卡 + 最近会话卡；分类工具卡；最近会议 + 行动项。使用真实已加载记录，不添加虚构指标。
- 材质：浅灰背景、白色表面、克制的玉青色；深色用独立的炭灰表面和低饱和青色，不做简单反色。录音沿用朱红。
- 几何：页面间距 24–40px；卡片间距 16–18px；卡片圆角 20–24px；控件 9–13px；字号 12/13/16/20/28/34px。
- 阴影：`--shadow-card` 静态表面，`--shadow-float` 可点击卡片悬停。静态卡片不伪装成可点击控件。
- 动效：控件反馈 150–180ms，卡片与筛选 200–220ms，路由进入 240ms；采用 transform/opacity。页面转换不重挂载全局子树，不延迟用户输入。
- 响应式：首页以可用内容宽度为准，650px 以下单列，380px 以下收起装饰。小窗口展开侧栏为覆盖层，可点击遮罩关闭。
- 状态：筛选使用 `aria-pressed`；主题是支持方向键/Home/End 的 radio group；参数折叠使用 button + aria-expanded；遵循减少动态效果设置。
- 设置：已访问标签页保留挂载，输入草稿不因切换分类丢失。现有本地数据读取、录音与导入流程不变。

主要实现：`frontend/src/app/bento.css`、`HomeOverview.module.css`、`ThemeToggle.tsx`。验证材料与结果见 `docs/design-v2.md`。
